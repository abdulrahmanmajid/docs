The Kallabot API is the same API the Kallabot dashboard runs on. Anything you can do with an agent in the app, you can script: create and publish agents, place phone calls, start browser calls, read transcripts and recordings, manage numbers, and get a signed webhook the moment something happens.

```bash
curl https://api.kallabot.com/v1/agents \
  -H "Authorization: Bearer $KALLABOT_API_KEY"
```

## Conventions you can rely on

Every endpoint follows the same rules, so you learn them once.

| Convention | What it means | Guide |
| --- | --- | --- |
| Scopes | Each operation lists the scopes a key needs (`x-required-scopes` in the spec). | [Authentication](/developers/authentication) |
| Stable error codes | Every error has a machine `code` that never changes. Match on it, not on the message. | [Errors](/developers/errors) |
| Safe retries | Creates and control actions take an `Idempotency-Key`. A retry never runs twice. | [Idempotency](/developers/idempotency) |
| No lost updates | Changes to agents and calls send `If-Match` with the revision you read. | [Concurrency](/developers/concurrency) |
| Cursor pagination | Lists return `data`, `has_more` and `next_cursor`. | [Pagination](/developers/pagination) |
| Rate limit headers | Every authenticated response says how much budget is left. | [Rate limits](/developers/rate-limits) |
| Request IDs | Every response has an `X-Request-Id`. Quote it to support. | [Request IDs](/developers/request-ids) |

## What the API doesn't do yet

We keep this list honest so you don't build on something that isn't there.

- **API keys are made in the dashboard.** A key can't create other keys. See [Authentication](/developers/authentication).
- **Replying to chats is dashboard-only for now.** API keys can read inbox threads and change their state. See [Inbox](/developers/inbox).
- **Connecting WhatsApp, Messenger and Instagram** happens in the dashboard through Meta sign-in.
- **No campaigns API.** To call a list, loop over it with [`POST /v1/calls`](/developers/calls) or [schedule calls](/developers/calls#schedule-a-call-for-later).
