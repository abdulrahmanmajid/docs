This reference is generated from the Kallabot backend's own route definitions on every release, so it always matches what the API does. Each endpoint page shows its parameters, request and response schemas, the scopes its key needs, and a playground where you can send a real request with your key.

## Sections

| Section | What's in it |
| --- | --- |
| **Agents** | Create, validate, version, publish and archive agents. |
| **Calls** | Place, list, read, cancel and annotate calls; transcripts, recordings, events; whisper, listen-in, take-over and transfer. |
| **Scheduled calls** | Book outbound calls for later and confirm callbacks. |
| **Web calls** | Start browser voice calls over WebRTC. |
| **Tools** | HTTP API tools, MCP servers, Google Sheets tools, and the credentials they use. |
| **Knowledge** | Add, edit, resync and delete knowledge sources (text, websites, Google Sheets, files); search; import catalogs. |
| **Numbers** | Countries, available numbers, buying, line settings, caller numbers, port-ins. |
| **SIP trunks** | Bring your own carrier over SIP and attach its numbers. |
| **Inbox** | Chat threads across WhatsApp, Messenger, Instagram and web chat, and their state. |
| **Web chat** | Website chat widgets. |
| **Webhooks** | Endpoints, deliveries, retries, recovery and the event catalogue. |
| **Minutes** | Minutes balances, minute requests and moving minutes. |
| **Billing** | Plans, the billing summary, invoices, checkout and portal links, subscription changes, seats and auto top-up. |

Webhook events are documented here too: each of the 35 events has its own page with its payload schema.

## Reading an endpoint page

- **Scopes.** Each description ends with the scopes the key needs, like **Scopes:** `call:read`, `call:content`. Missing one returns `403 insufficient_scope`.
- **Headers.** `Idempotency-Key` is marked required on every operation that needs it. `If-Match` appears where it applies; [Concurrency](/developers/concurrency) lists where it's required. See also [Idempotency](/developers/idempotency).
- **Responses.** Every endpoint can return the [standard errors](/developers/errors) (`401`, `403`, `422`, `429`, `500`) as `application/problem+json`. Successful responses carry the [`RateLimit-*`](/developers/rate-limits) and `X-Request-Id` headers.

## Use the spec

The OpenAPI 3.1 document behind this reference can be downloaded from the menu at the top of any endpoint page. Every operation carries `x-required-scopes`. Load it into Postman, Insomnia or an OpenAPI client generator to get a typed client.

<Info>
  The API reference covers what an API key can call. Dashboard-only actions (creating API keys, connecting WhatsApp and Meta accounts, replying to chats) aren't listed here.
</Info>
